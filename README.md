# OriginOS消息岛

适用于 vivo/iqoo OriginOS 的 LSPosed 消息上岛模块，将微信、QQ 等应用的通知接入 vivo 原生原子岛，提供消息预览、未读数量、详情卡片、快捷回复和下拉小窗等功能，同时保留通知栏中的原始通知。

> **本仓库为第三方修改分支（0.1.33）**
> 基于原作者 [joelau0503/originos-notify-island](https://github.com/joelau0503/originos-notify-island) 0.1.31 源码继续开发，全部改动见 [CHANGES.md](CHANGES.md)，可直接安装的构建产物在 [dist/OriginOS-Notify-Island-0.1.33.apk](dist/OriginOS-Notify-Island-0.1.33.apk)。
> 主要新增：多岛共存与挤压、单岛宽度自适应、卡片环境色渐变、第三方通话岛（微信/QQ 等，从接听开始计时）、设置页重排与即时生效。

## 本分支改动（0.1.33）

横屏跟随状态栏：状态栏收起时，消息胶囊和中央卡片不再强制常驻在横屏应用中央；下滑状态栏后，沿用 SystemUI 原生逻辑恢复显示。数据层与窗口层双重门控，反射接口不匹配时安全回退原生。其余消息、卡片、手势和通话岛功能保持不变。

显示样式拆成左右两个独立选项：左侧选联系人头像 / 应用图标，右侧选联系人名字 / 消息内容；右侧选消息内容时，联系人名字自动回到左侧。

这一版在原版 0.1.31 的基础上继续往下做，目标是“岛更好用”——能同时装下更多东西、卡片更好看、通话也能上岛、改设置不用重启手机。

**能同时看到更多东西**

- 消息岛不再独占原子岛，可以和系统自己的音乐岛、导航岛、通话岛同时出现，彼此挤压让位，各自缩小成合理尺寸。
- 单个消息岛的宽度按左边、右边实际内容分别计算，内容短就紧贴屏幕边缘，不再被固定撑成对称宽度。
- 只跳过“正在播放”的媒体通知（音乐、视频播放时交给原生岛），下载进度、上传、其他常驻通知都照常上岛，不再被误吞。

**卡片更好看**

- 长按展开的卡片背景会跟着内容取色：左半取发送人头像的主色，右半取应用图标的主色，中间自然过渡并带柔和光晕，同时压住高光的刺眼感。

**通话也能上岛**

- 微信、QQ 等第三方应用的语音通话会显示在岛上：左侧是对方头像和名字，右侧是从接通开始走的秒表。
- 还没接通时显示“正在呼叫”，真正接通那一刻才开始计时，不会把回铃时间算进去。
- 和消息岛可以共存：有新消息时消息占主岛，通话自动缩成左侧的小球，互不遮挡。
- 系统电话不上岛，保持原生拨号界面不变。

**设置更好用**

- 设置页重新分组成四块：运行状态、消息岛·内容、通话岛·实时状态、停留与消失。
- 显示样式拆成左右两组独立选项：左侧联系人头像 / 应用图标，右侧联系人名字 / 消息内容，互不影响。
- 所有开关、样式、滑杆改完立刻生效，不用重启手机，已显示在岛上的内容会原地刷新。
- 新增“接通计时延迟”滑杆（0–800ms），觉得计时比通话界面早一点或晚一点都可以自己微调。

**下载与安装**

在 [Releases](https://github.com/6I0IM77/originos-notify-island/releases/latest) 里下载。覆盖安装即可，LSPosed 作用域与激活方式和原版一致。

## 主要功能

- 将选定应用的消息显示在原子岛
- 支持发送者、消息内容和未读数量显示
- 支持紧凑显示和加宽显示
- 长按消息岛打开消息详情卡片
- 在详情卡片中回复或关闭消息
- 下拉详情卡片，以小窗模式打开对应应用
- 支持原生左滑、右滑关闭消息岛
- 保留通知栏原始通知，仅过滤重复的顶部横幅
- 消息仅在本机处理，不上传通知内容

0.1.25版本新增功能：

- 显示发送人头像功能：使用通知中的发送人头像；没有头像时使用应用图标。
- 只显示发送人和头像功能：左侧显示发送人和头像，右侧显示“微信消息”“QQ消息”等；与上一个功能互斥。

0.1.30优化和新增内容：

- 新增“仅显示应用名称”及头像子开关，与其他显示模式互斥；无头像时回退应用图标。

- 优化“仅显示发送人”：头像独立控制，仅在左侧显示。

- 优化胶囊自适应：按左右较长内容调整尺寸，取消固定最小宽度；

- 修正发送人、应用名称及未读徽标的宽度计算，超出上限才滚动。

- “加宽显示”更名为“扩展显示”：开启使用固定扩展尺寸，关闭恢复自适应。

- 未读数量改为深灰底、白色小数字圆角徽标，超过 99 显示 99+。

- 卡片新增“小窗回复”按钮，点击打开应用小窗完成回复，保留下拉小窗手势。

- 优化应用选择：勾选、取消、全选及反选时位置不变，完成保存后下次打开再调整置顶。

## 使用要求

- 已 Root 的 vivo/iqoo 手机
- 已安装并启用 LSPosed
- Android 15 / API 35 或更高版本
- vivo/iqoo OriginOS 原子岛功能可用
- 当前主要针对 vivo X300 Pro、OriginOS 6 适配

## 安装方法

1. 安装 `OriginOS消息岛.apk`
2. 打开 LSPosed，启用本模块
3. 为模块勾选以下作用域：
   - 系统界面：`com.android.systemui`
   - 系统界面组件：`com.vivo.systemuiplugin`
4. 重启手机，使系统进程重新加载模块
5. 打开“通知上岛”应用，确认页面显示：
   - LSP 已连接
   - 通知采集已连接
   - 原子岛显示服务已连接
6. 在应用选择页面勾选需要接入原子岛的应用
7. 使用微信、QQ 或其他选定应用发送一条测试消息

## 使用说明

默认处理微信和 QQ 通知，也可以在应用选择页面搜索、全选、反选或取消选择应用。

收到消息后，消息岛左侧显示发送者，右侧显示消息内容，最右侧显示未读数量。消息内容较长时会自动滚动显示。

长按消息岛可以打开消息详情卡片。下拉详情卡片可以进入对应应用的小窗模式，点击“回复”可以使用通知提供的快捷回复入口。

## 当前适配情况

已在 vivo X300 Pro、OriginOS 6、Android 16 & IQOO 13、OriginOS 7、Android 17上进行功能验证。

OriginOS 5、OriginOS 7已做离线适配，未做实机测试，欢迎反馈bug，反馈入口在版本发布说明中。

本项目需要系统级 Hook 权限，仅建议在了解 Root、LSPosed 和系统界面模块风险的情况下使用。
