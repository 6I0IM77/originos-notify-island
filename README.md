# 通知上岛（OriginOS 消息岛 · 第三方修改分支）

适用于 vivo / iQOO OriginOS 的 LSPosed 模块：把微信、QQ 等应用的通知接入系统原生原子岛，提供消息预览、未读数量、详情卡片、快捷回复、下拉小窗与通话计时等功能，同时保留通知栏中的原始通知。

> 基于原作者 [joelau0503/originos-notify-island](https://github.com/joelau0503/originos-notify-island) 0.1.31 源码继续开发，当前版本 **0.1.33**（versionCode 37），沿用原模块签名，可覆盖安装。完整改动记录见 [CHANGES.md](CHANGES.md)，安装包在 [Releases](https://github.com/6I0IM77/originos-notify-island/releases/latest) 下载。

## 相对原版 0.1.31 的改动

### 多岛共存与宽度自适应

- **不再独占原子岛**：消息岛可与系统音乐岛、导航岛、通话岛同时出现，彼此挤压让位，各自缩成合理尺寸。
- **左右分别收紧宽度**：单岛宽度按左侧、右侧实测内容分别计算，内容短就贴近屏幕边缘；窄宽度下不再把末位文字切半。
- **播放通知过滤收窄**：只有“正在播放”的音乐 / 视频 / 直播媒体通知交给原生媒体岛；下载、上传、安装等带进度的常驻通知照常上岛。

### 卡片外观与小窗转场

- **环境色渐变背景**：展开卡片左半取发送人头像主色，右半取应用图标主色，沿弧线自然过渡并叠加柔光，同时压制高光刺眼感；取色失败退回图标主色。
- **小窗转场更稳**：没有剪影可沿用时延迟撤掉源岛；转场动画放慢、剪影保持到原生小窗在下方合成，避免岛屿和窗口同帧消失，或提前透出底层。

### 第三方通话岛

- 微信、QQ、TIM 等第三方语音 / 视频通话上岛：左侧联系人头像与名字，右侧接通后走秒表；未接通显示“正在呼叫”，对方接听那一刻才开始计时，回铃时间不计入。
- 通话与消息可共存：新消息占主岛，通话缩成左侧小球；系统电话不上岛，保持原生拨号界面。
- **识别更准**：按 ongoing 事件、全屏意图、接听 / 拒绝 / 挂断按钮及通知文案综合判定；读取 Android 12 通话通知 `callType` 区分来电与接通；QQ 类不带“通话”字样的呼叫文案也能识别。
- 通话通知只保留对方名字供点击路由，不计未读、不占主岛；对方名字 / 头像可通过实时回查补全。
- 通话相关设置：通话上岛、显示联系人头像、所有应用通话上岛（关闭后仅微信 / QQ / TIM）、接通计时延迟滑杆（0–800ms，默认 300ms）。

### 显示样式与设置即时生效

- 显示样式由原版“四选一互斥”改为**左右两个独立选项**：左侧 = 联系人头像 / 应用图标，右侧 = 联系人名字 / 消息详细内容；右侧选消息内容时，联系人名字自动回到左侧。
- 所有开关、样式、滑杆写入后立即通过广播重绘当前岛，不用重启手机；已显示在岛上的内容原地刷新。
- 模块日志直写 logcat，手机侧抓日志即可看到通话状态与横屏门控诊断。

### 横屏跟随状态栏

- 状态栏收起时，消息胶囊 / 中央卡片不再强制常驻在横屏应用中央；下滑状态栏后由 SystemUI 原生逻辑恢复显示。
- 数据层与窗口层双重门控：优先读原生状态栏回调状态，接口缺失时回退通知面板 / QS 展开标志；窗口 force 标志只在本次调用内临时抬高并恢复，不跨岛泄漏；反射签名或字段不匹配时安全回退原生调用，模块不崩溃。覆盖 OriginOS 5 / 6 / 7 插件。

## 保留的原版功能

- 选定应用的消息显示在原子岛，显示发送人、消息内容与未读数量；紧凑 / 扩展两种胶囊尺寸。
- 手势打开消息，可快捷回复或关闭；下拉卡片以小窗打开对应应用；支持原生左滑、右滑关闭。
- 保留通知栏原始通知，仅过滤重复的顶部横幅；通知内容只在本机处理，不上传。

## 使用要求

- 已 Root 的 vivo / iQOO 手机，已安装并启用 LSPosed。
- Android 15 / API 35 或更高版本，OriginOS 原子岛功能可用。
- 模块作用域：系统界面 `com.android.systemui`、系统界面组件 `com.vivo.systemuiplugin`。

## 安装方法

1. 从 [Releases](https://github.com/6I0IM77/originos-notify-island/releases/latest) 下载 APK 安装。
2. 在 LSPosed 中启用本模块，勾选上述两个作用域。
3. 重启手机（或重启系统界面进程）使模块加载。
4. 打开“通知上岛”应用，确认 LSP、通知采集、原子岛显示服务三项已连接。
5. 在应用选择页勾选需要上岛的应用，用微信 / QQ 发一条测试消息验证。

## 使用说明

- 默认处理微信和 QQ 通知，也可在应用选择页搜索、全选、反选或取消选择。
- 消息岛左侧显示发送人 / 图标，右侧显示消息内容，最右侧为未读数量；内容较长自动滚动。
- 长按展开详情卡片；下拉进入应用小窗；点“回复”走通知提供的快捷回复入口。

## 适配情况与已知限制

- 主要在 vivo X300 Pro（OriginOS 6）上适配；OriginOS 5 / 7 已按系统插件文件做离线接口核验，未做实机验收，欢迎反馈。
- 通话联系人的名字与头像取自应用自身通知；通知不带对方信息时退回应用名与图标，属于数据源限制。
- 宽度、边界与横屏门控 hook 依赖 SystemUI 插件内部字段，系统大版本更新后可能失效；已有“接口不匹配即安全停用”保护。
- 不走语音通话通道的应用（普通录音、K歌、语音消息）不会被识别为通话。

## 构建

JDK 21、Android SDK 37、Build Tools 36.0.0、Gradle 9.5.1；配置 `ANDROID_HOME` 或 `local.properties` 后执行：

```bash
./gradlew :app:assembleRelease
```

横屏门控契约由 `tests/LandscapeContractCheck` 覆盖；其余纯 Java 检查与手势回归见 `tests/`、`tools/` 目录。
